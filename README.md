# funcionesPython (Python)

Módulo en Python desarrollado para la asignatura **Software Matemático y Estadístico**.

## Descripción

Librería de procesamiento y análisis estadístico implementada en Python. Incluye algoritmos de discretización, métricas (Varianza, Entropía, AUC), transformaciones (Normalización y Estandarización), filtrado de atributos y funciones de visualización gráfica.
